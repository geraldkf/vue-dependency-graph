# Playground Harness

## Goal

Build a dedicated Vue application to validate framework behaviour.

## Features

### Graph Explorer

Show:

- nodes
- dependencies
- status

### Event Console

Publish events.

### Transaction Console

Execute batched updates.

### API Simulator

Configure:

- delay
- failure rates
- polling completion

### Metrics Dashboard

View:

- execution count
- cache statistics

### Snapshot Export

Download current graph state.
