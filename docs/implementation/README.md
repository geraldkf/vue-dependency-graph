# Implementation history

[`01-roadmap.md`](./01-roadmap.md) is the maintained roadmap (see also
[`../ROADMAP.md`](../ROADMAP.md)).

Everything else here — the per-milestone plans, implementation notes,
validation handoffs, and the prompts used to drive them — is historical
build record, kept for traceability but not maintained as living
documentation. It's archived under [`archive/`](./archive/). For the
current state of the system, start at [`../architecture/`](../architecture/)
and [`../decisions/`](../decisions/) instead.
